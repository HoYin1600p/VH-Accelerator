# VH Accelerator 1.1.3

Version 1.1.3 adds an optional in-game settings screen. Nothing changes for
players who do not install Cloth Config.

## Download and compatibility

The release artifact is `VH-Accelerator-1.1.3.jar` for Minecraft 1.18.2 and
Forge 40.3.11 or later in the Forge 40.x line. Compatibility is unchanged from
[1.1.2](1.1.2.md). Do not install a sources JAR. The settings screen needs
[Cloth Config](https://www.curseforge.com/minecraft/mc-mods/cloth-config)
for Forge, 6.5.102 or newer; it is an optional dependency.

## Added

- **Settings screen.** Bind **Open VH Accelerator settings** in Options >
  Controls (it is unbound by default) and press it in a world. Every setting
  from `vhaccelerator-client.toml` and `vhaccelerator-common.toml` is on the
  screen, grouped into tabs: General, Launch & loading, Joining worlds, Vault
  Hunters, Mod compatibility, Memory, Server & engine, Backports and
  Diagnostics. Each setting shows a one-line summary; click it for a fuller
  explanation. A `(restart)` badge marks settings that only take effect after
  a restart. Save applies the rest at once, through the same paths as the
  `/vha` commands, and lists any changed setting that needs a restart.
- **Default and Experimental.** Default resets every setting to its shipped
  value. Experimental turns on the settings that ship off, except Diagnostics
  and `parallelAtlasStitching`, which has produced wrong textures in Vault
  packs. Both ask first and list what they will change.
- **Report a bug.** The Diagnostics tab opens a preview of a pre-filled GitHub
  issue: versions, GPU and driver, related mods, VH Accelerator's main
  switches and every changed setting. User folders, your Minecraft name and
  your UUID are removed before anything is shown. It can copy the newest crash
  report to your clipboard and open the issue in your browser; VH Accelerator
  uploads nothing, and you submit the issue yourself.
- **Fixed layout.** The settings screen, its dialogs and the preview are laid
  out at 960 x 540 GUI units at every resolution, so they look the same at
  1080p, 1440p and 4K. Your own GUI scale returns when you close them.

## Changed

- **Update notices.** If you skip a critical release, the update notice stays
  critical even when the newest release is a normal one, and shows the critical
  release's message. Before, only the newest release counted, so the default
  critical-only filter could hide a critical fix. This works from 1.1.3 on.

Without Cloth Config, VH Accelerator runs exactly as before; pressing the key
prints a chat message pointing to the two config files.

See [Settings screen](../CONFIGURATION.md#settings-screen) for the details.
