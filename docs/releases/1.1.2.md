# VH Accelerator 1.1.2 — critical fix

Version 1.1.2 fixes parts of the world going missing for players who also run
Farsight. Everyone on 1.1.0 or 1.1.1 with Farsight installed should update.

## Download and compatibility

The release artifact is `VH-Accelerator-1.1.2.jar` for Minecraft 1.18.2 and
Forge 40.3.11 or later in the Forge 40.x line. Compatibility is unchanged from
[1.1.1](1.1.1.md). Do not install a sources JAR.

## Fixed

- With Farsight installed, parts of the world could disappear and stay gone
  until a relog (`boundFarsightChunkRetention`). The missing blocks were
  invisible and could not be walked on. It showed up most in vaults, for
  example a hallway and portal room that were fine on the way in and empty on
  the way back.

  Farsight keeps chunks on the client after the server unloads them, so you
  can see further than the server's view distance. Since 1.1.0, VH Accelerator
  releases the chunks Farsight keeps beyond your render distance, which were
  never drawn and only used memory. It chose them by distance from the player
  alone. The server tracks your position slightly behind your client, most of
  all while flying, so a chunk could be released on your side while the
  server still counted it as sent. The server resends a chunk only after it
  has unloaded it, so that part of the world never came back until you
  relogged.

  VH Accelerator now releases only chunks the server has already unloaded, so
  the server always sends them again when you return. Chunks within your
  render distance are kept, as before.

Players who worked around the problem by setting
`boundFarsightChunkRetention = false` can set it back to `true` after
updating. Players without Farsight were not affected.
