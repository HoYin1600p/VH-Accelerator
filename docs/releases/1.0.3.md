# VH Accelerator 1.0.3

Release date: July 28, 2026

VH Accelerator 1.0.3 fixes missing placeholder textures in Sophisticated
Storage container screens.

## Download

Install the non-sources artifact:

```text
VH-Accelerator-1.0.3.jar
```

Do not install the `-sources.jar` as a mod.

## Fixed

- Empty upgrade slots in Sophisticated Storage barrels and limited barrels now
  display their intended placeholder texture instead of a black-and-purple
  missing-texture square.
- Related inaccessible, tank, and battery slot placeholders from Sophisticated
  Core are protected by the same compatibility correction.

The correction activates only when Sophisticated Core is installed. It does
not add a hard dependency on Sophisticated Storage or Sophisticated Core.

## Upgrade

1. Stop Minecraft.
2. Disable or remove the previous VH Accelerator jar.
3. Place `VH-Accelerator-1.0.3.jar` in the `mods` directory.
4. Keep only one active VH Accelerator jar.

No configuration reset or cache deletion is required. Fully restart the client
so the corrected block texture atlas is rebuilt.

## Compatibility

This patch retains the established Minecraft 1.18.2, Forge 40.3.11+, Vault
Hunters, and JEI compatibility baselines from 1.0.2.
