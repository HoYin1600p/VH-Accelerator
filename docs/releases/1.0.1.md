# VH Accelerator 1.0.1

Release date: July 28, 2026

VH Accelerator 1.0.1 is a focused patch for accurate Compare Mode
benchmarking.

## Download

Install the non-sources artifact:

```text
VH-Accelerator-1.0.1.jar
```

Do not install the `-sources.jar` as a mod.

## Fixed

- Compare Mode is read directly from the common config before Forge attaches
  that config to the mod.
- Early mixin paths now see the correct Compare Mode value, including the
  asynchronous user-service path.
- Cache preloading, client asset fingerprinting, model and blockstate
  preparation, JEI preparation, and optional-mod startup work no longer begin
  during a Compare Mode launch.
- The captured value remains stable for the complete launch, avoiding a
  partially optimized baseline.
- The log now confirms when Compare Mode was captured during bootstrap and
  when all client optimization startup groups were skipped.

Timers and selected diagnostics remain active in Compare Mode as intended.
The `[COMPARE]` marker remains visible beside the main-menu launch timer.

## Upgrade

1. Stop Minecraft.
2. Disable or remove the previous VH Accelerator jar.
3. Place `VH-Accelerator-1.0.1.jar` in the `mods` directory.
4. Keep only one active VH Accelerator jar.

No config reset or cache deletion is required.

## Compatibility

This patch retains the 1.0.0 compatibility baseline:

- Minecraft 1.18.2;
- Forge 40.3.11 through 40.x;
- Vault Hunters Remastered `20.0.3-remastered.6872`;
- Vault Hunters official `3.21.5.6882` and `3.21.6.6884`;
- custom MVP `3.21.62`;
- JEI `9.7.2.1001` and `10.2.1.1009`.

Vault Hunters, JEI, and ModernFix remain optional dependencies. The same jar
is safe to load on a physical client or dedicated server.
