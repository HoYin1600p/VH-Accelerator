# VH Accelerator 1.0.2

Release date: July 28, 2026

VH Accelerator 1.0.2 corrects launch-time reporting so comparisons include
the complete Java process startup.

## Download

Install the non-sources artifact:

```text
VH-Accelerator-1.0.2.jar
```

Do not install the `-sources.jar` as a mod.

## Fixed

- Client launch timing now begins at JVM process start.
- ModLauncher, mixin discovery, and other early bootstrap time are included
  before Minecraft reaches its client entry point.
- Dedicated-server launch timing uses the same full-process measurement.
- The timer remains monotonic by reconstructing process start from JVM uptime
  rather than subtracting wall-clock timestamps.
- The log reports how many milliseconds elapsed before the timer attached at
  Minecraft's entry point.

This corrects an under-report of roughly nine seconds in the VaultCrafters
test instance. It changes measurement only and does not add, remove, or alter
an optimization.

## Compare Mode

The Compare Mode bootstrap correction from 1.0.1 remains in place. A Compare
Mode launch suppresses VH Accelerator optimizations while retaining the newly
corrected full-process timer and selected diagnostics.

Other installed performance mods and independently optimized custom mods
remain active. Compare Mode measures VH Accelerator's contribution in the
otherwise unchanged instance; it does not emulate removing every performance
mod.

## Upgrade

1. Stop Minecraft.
2. Disable or remove the previous VH Accelerator jar.
3. Place `VH-Accelerator-1.0.2.jar` in the `mods` directory.
4. Keep only one active VH Accelerator jar.

No config reset or cache deletion is required.

## Compatibility

This patch retains the established compatibility baseline:

- Minecraft 1.18.2;
- Forge 40.3.11 through 40.x;
- Vault Hunters Remastered `20.0.3-remastered.6872`;
- Vault Hunters official `3.21.5.6882` and `3.21.6.6884`;
- custom MVP `3.21.62`;
- JEI `9.7.2.1001` and `10.2.1.1009`.

Vault Hunters, JEI, and ModernFix remain optional dependencies. The same jar
is safe to load on a physical client or dedicated server.
