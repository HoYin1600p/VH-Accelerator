# VH Accelerator 1.1.4

A maintenance update. Nothing changes in how the mod behaves, and your settings
carry over.

- Timer, JEI rebuild and update-notice messages can now be translated. The
  English text is the same.
- VH Accelerator now has a logo and a fuller description in the Mods list.
- Behind the scenes, the code was reorganised and tidied, with new tests
  proving it behaves exactly like 1.1.3.
