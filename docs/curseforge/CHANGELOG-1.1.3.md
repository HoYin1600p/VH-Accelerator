# VH Accelerator 1.1.3

Adds an optional in-game settings screen.

- Install Cloth Config (Forge 6.5.102 or newer), then bind **Open VH
  Accelerator settings** in Options > Controls and press it in a world.
- Every setting is there, grouped into tabs, with a short explanation for each
  and a (restart) badge on the ones that need a restart.
- **Default** resets everything; **Experimental** turns on the settings that
  ship off. Both ask first.
- **Report a bug** (Diagnostics tab) prepares a GitHub issue with your versions
  and changed settings, with your name and folders removed. Nothing is
  uploaded.
- Without Cloth Config nothing changes; your settings stay in the config files.

[Read the detailed changelog on GitHub](https://github.com/HoYin1600p/VH-Accelerator/releases/tag/v1.1.3)
