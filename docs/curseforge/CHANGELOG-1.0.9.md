## 1.0.9 — JEI Recovery Pass

**Added**

- Added `/vha reload_jei` to rebuild JEI from the recipes and tags already
  synchronized to your client without disconnecting.
- The command reports when the rebuild finishes and how long it took.

**Compatibility**

- Added compatibility verification for Wolds Vaults 0.33.0.

No configuration reset or cache deletion is required when updating.
